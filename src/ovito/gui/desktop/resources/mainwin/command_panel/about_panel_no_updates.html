Welcome to m-ovito

m-ovito is a modified research build based on OVITO, extended for molecular simulation analysis workflows.

Help and resources

For original OVITO documentation and general OVITO usage, visit www.ovito.org.

For community OVITO support, visit the OVITO support forum.

For m-ovito source code and modified-build information, visit github.com/blualg/m-ovito.
